Budget Bit — Dish-Level Food Insight & Expense Tracker

Live App GitHub
Why I built this:

Most expense tracking apps make you manually type out every single meal and line item. I wanted to see if I could eliminate that friction by allowing users to simply take a photo of a restaurant receipt and have the application automatically extract each dish and price.

What I engineered:
  • Integrated the Google Cloud Vision API to build an OCR extraction pipeline that accurately recognizes dish names, quantities, and prices (~85% extraction accuracy).
  • Designed REST API endpoints using Node.js and Express, writing normalized relational tables in PostgreSQL to store users, restaurant visits, itemized dishes, and spending history.
  • Built a per-dish multi-vector rating system (taste, value, portion) so users can see what was actually worth ordering.
  • Wrote automated end-to-end regression tests using Selenium covering user login, receipt upload, and budget calculation flows.
Key challenge & learning:

Real receipts come in all formats—crinkled paper, faded thermal ink, and irregular line spacing. Learning how to clean and parse raw bounding-box text from the OCR response taught me a ton about data cleaning and defensive API design.

React Node.js Express.js PostgreSQL Google Cloud Vision Selenium QA Postman
Computer Vision • MediaPipe • Pose Estimation

AI Virtual Dressing Room — Real-Time Try-On System

Live App GitHub
Why I built this:

Most virtual try-on software relies on heavy 3D rendering engines or proprietary hardware. I wanted to build a fast, lightweight 2D computer vision pipeline that runs smoothly in real time on any standard laptop webcam.

What I engineered:
  • Implemented real-time 33-point anatomical landmark detection using Google's MediaPipe Pose model, tracking shoulders, chest, and hips across changing lighting.
  • Calculated torso aspect ratios and affine transformation matrices using NumPy and OpenCV to dynamically warp, scale, and composite garment images onto the user's live video stream.
  • Engineered the entire computer vision pipeline solo: landmark extraction → bounding box calculation → perspective homography warp → alpha channel blending.
Key challenge & learning:

Naive image resizing creates awkward stretching whenever the user moves closer or turns. Solving this required implementing vector calculations between shoulder and hip keypoints to maintain correct clothing proportions at 30+ FPS.

Python OpenCV MediaPipe NumPy Pose Estimation TensorFlow

Rehab AI — AI-Powered Home Physical Therapy Coaching

Live App GitHub
Why I built this:

When patients do rehab exercises at home without a physical therapist watching, it's very easy to use bad form or fail to reach the proper range of motion, risking re-injury. I wanted to build an assistant that gives live feedback on exercise angles.

What I engineered:
  • Built a kinematic angle calculator that determines the 3-point joint angle (e.g. hip-knee-ankle) dynamically across movement phases in real time.
  • Configured visual and audio alerts: green when a patient hits proper range (e.g. squat depth ≤ 90°) and warning cues when posture deviates.
  • Implemented automated repetition counting based on peak flexion and full extension cycles, eliminating the need to count reps manually.
  • Wrapped the pipeline into a responsive web interface built with React.js.
Key challenge & learning:

Camera feeds have noise: tiny landmark jitters can cause false angle measurements and incorrect rep triggers. I implemented exponential moving averages and angle threshold buffers to ensure reps are only counted on clean, intentional repetitions.

Python OpenCV OpenVINO / MediaPipe React.js Biomechanical Kinematics
